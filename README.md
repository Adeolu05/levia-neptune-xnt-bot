# Neptune Privacy Community Bot

This repository contains the Phase 1 Telegram bot foundation for the Neptune Privacy
ecosystem. It currently provides only `/start`, `/help`, and `/about`.

Blockchain data integration is intentionally not implemented. The live explorer API and
node identity must pass the verification gate documented in
[`docs/implementation-plan.md`](docs/implementation-plan.md) before any statistics
command is added.

## Requirements

- Node.js 22 or newer (Node.js LTS recommended)
- A Telegram bot token created with BotFather for local development

## Local development

1. Install dependencies:

   ```powershell
   npm install
   ```

2. Copy `.env.example` to `.env` and replace the placeholder with the token
   generated by BotFather. The application loads `.env` automatically.

3. Start long polling:

   ```powershell
   npm run dev
   ```

The bot registers its command menu with Telegram at startup. No real Telegram
connection is included in automated tests; use a disposable development token if
you perform a manual smoke test.

## Checks

```powershell
npm run test
npm run lint
npm run build
npm run format:check
```

## Project boundaries

The current phase does not include live blockchain statistics, guessed API/RPC URLs,
wallets, transactions, PostgreSQL, Redis, WebSockets, or chart rendering.
